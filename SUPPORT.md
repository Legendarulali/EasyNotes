# Reporting Bugs & Requesting Features

Found a bug, visual glitch, or have an idea to improve **EasyNotes**? You can report it directly through GitHub Issues so we can fix or include it in the next release.

## How to Open an Issue
1. Go to the **[Issues](https://github.com/Legendarulali/EasyNotes/issues)** tab at the top of this repository.
2. Click the green **New issue** button.
3. Choose a clear, descriptive title (e.g., `[Bug] Infinite canvas PDF export cuts equations across pages` or `[Feature] Change stroke color after selection`).
4. Include the following details in the description:
   - **Platform & OS Version:** (e.g., Windows 11 24H2, Android 15 / One UI 7)
   - **App Version:** (e.g., `v1.0.0`)
   - **Steps to Reproduce:** What you clicked or drew before the issue happened.
   - **Expected vs. Actual Behavior:** What should have happened vs. what actually happened.
   - **Screenshots / Exported Files:** Drag and drop screenshots, error popups, or sample PDFs directly into the text box.

## Known Issues (Tracked for `v1.0.1`)
- **Infinite Canvas PDF Export:** Large whiteboards can split handwriting awkwardly across horizontal page boundaries.
- **Post-Selection Recoloring:** Changing the color of handwritten strokes after they have already been drawn is planned for `v1.0.1`.
